# Бесплатный маршрут без квоты Workers — 30 октября 2026

## Причина изменения

У короткого HTTP relay каждый запрос диапазона, upload и idle poll расходует
суточную квоту Workers. Аналитика аккаунта показала около 81 тысяч запросов
за день, из них около 76 тысяч у `tg-ws-bridge`. Несколько Workers в одном
аккаунте не увеличивают общий лимит. Платный тариф не подключался.

У владельца нет подходящего домена; доступный Cloudflare API не показывает
DNS-зон. Поэтому новый режим использует публичный CF-пул апстрима, без
покупки домена, регистрации дополнительных аккаунтов и собственных серверов.

## Маршруты Windows 1.15.0 / Android 0.5.0

- Обычные соединения сохраняют WebSocket и TCP fallback.
- Для медиа сначала пробуется HTTPS `/api` с HTTP/2 через CF DNS proxy.
  Несколько запросов используют общий H2 connection pool; Worker не участвует.
- Общий встроенный Worker больше не включён по умолчанию. Бесплатный CF-пул
  включён. Если H2 недоступен, остаются свободные от Workers маршруты WS/TCP.
- `--no-h2` / «HTTP/2 для медиа» позволяют отключить только новый транспорт.
  Старый переключатель порта 80 относится к WS/Worker; H2 всегда использует
  TLS с проверкой сертификата.
- Worker остаётся ручной опцией. При его явном включении квота Workers снова
  применима. Старый backend сохранён для совместимости, не изменён и не удалён.

## Перенос повторов

Telegram `/api` не поддерживает наш протокол byte offsets/ACK. Вместо повтора
8–32 KiB диапазона повторяется целый, неизменённый зашифрованный MTProto-пакет.
До трёх попыток разрешено для небольших encrypted-пакетов при ошибке HTTP;
это не сбрасывает соседние H2-потоки и не уменьшает размер или окно.
Неавторизованный handshake автоматически не дублируется.

Транспорт разбирает abridged/intermediate/padded intermediate, снимает только
транспортный padding и восстанавливает framing ответа. Содержимое сообщений
MTProto не расшифровывается. Неполный HTTP body не передаётся клиенту.
Для idle media connections предусмотрен ограниченный replay недавно
отправленного encrypted-пакета, по подходу апстрима.

Ограничения памяти: пакет до 4 MiB, до 8 обычных запросов на локальное
соединение и 8 MiB исходящих данных; глобально 16 обычных и 8 idle poll slots.
Результаты ограничены 4 MiB на запрос. Повторы не отключают проверку TLS.

## Миграция настроек

Desktop `routing_defaults_version=2` и Android `routing-defaults-v2` отключают
только старый известный встроенный Worker и включают бесплатный CF-пул.
Порт, secret, пользовательские домены и явный отказ от H2 сохраняются.
Произвольные пользовательские Worker-настройки не удаляются. После миграции
ручной opt-in в Worker также сохраняется при следующем запуске.

Обновление старых приложений обязательно: версии 1.14.x/0.4.x продолжают
пользоваться прежним Worker и расходовать квоту, пока не будут обновлены.
Новый режим не увеличивает квоту аккаунта — он не использует Workers.

## Проверки

1. Через SSH SOCKS с выходом в сеть Windows проверены четыре домена для
   DC2/DC4: в восьми случаях negotiated HTTP/2 и `ServerDHParamsOk`.
2. Python H2 client: 64 handshake, 48 128 байт MTProto-ответов за 75,2 s.
   Квота нашего Worker не используется; обращения идут к CF-доменам апстрима.
3. Новый Rust CLI запущен нативно на Windows на отдельном loopback-порту.
   Обычный DC2 через WS: 64 handshake за 70,8 s. Media DC2 через H2:
   64 handshake за 77,9 s. Рабочий Windows-прокси и VPN не заменялись.
4. Rust CLI/Linux также прошёл req_DH для DC2/DC4/media DC2.
5. Локальный настоящий H2-сервер проверяет: ответ 512 KiB без потери байтов,
   единичный HTTP 503 с повтором только нужного пакета, здоровый медленный
   сосед без отмены и отклонение неполного body.
6. Проверены fragmented CTR/framing всех трёх транспортов, padding, миграция
   старого Worker без потери secret/порта и сохранение явного H2 opt-out.
7. Android APK собран локально: 0.5.0/code 15, прежний сертификат подписи.
   На телефон ничего не устанавливалось; воспроизведение видео не проверялось.

Handshake не является доказательством непрерывной загрузки видео. Большой
ответ проверен на стенде, а не из Telegram-аккаунта. Доступность публичных
доменов зависит от владельцев и сети; отсутствие квоты Workers не означает
отсутствие всех возможных сетевых ограничений.
