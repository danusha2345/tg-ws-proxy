# Ключ подписи Android

Постоянный ключ проекта дополнительно сохранён локально в
`$HOME/.config/tg-ws-proxy-signing/android-release.p12`. Параметры для сборки
находятся рядом в `android-release.env`; оба файла имеют права `0600`, каталог
— `0700`. Ключ и пароли не входят в репозиторий.

Копия перенесена из GitHub Secrets только в OpenPGP-зашифрованном artifact,
расшифрованном локальным ключом восстановления. Сертификат локального PKCS#12
проверен против уже установленного APK. SHA-256 сертификата:

```text
7d8f33bc9b27bcb3c084dac03736b7869c28a6038de4677181f92b32eec593aa
```

Для локальной сборки загрузите переменные в окружение без их вывода:

```bash
set -a
. "$HOME/.config/tg-ws-proxy-signing/android-release.env"
set +a
cd android
./gradlew testDebugUnitTest lintRelease assembleRelease
```

Не использовать `set -x`, не печатать env-файл и не передавать пароли в
аргументах командной строки. Перед публикацией проверять APK через apksigner
и сверять сертификат со значением выше. GitHub Secrets сохранены для CI.

## YubiKey 5

Существующий ключ — RSA-4096. Импорт такого ключа в PIV требует YubiKey 5
с firmware 5.7+. Сам ключ при аппаратной подписи не покидает устройство,
но YubiKey должен быть подключён к компьютеру, выполняющему подпись.
GitHub-hosted runner не имеет доступа к локальному USB-ключу.

Альтернатива — хранить зашифрованный keystore локально, используя YubiKey для
защиты его расшифрования. Выбор режима, слота, PIN и touch policy выполняется
отдельно после получения устройства. Текущие PIV/OpenPGP-слоты не изменялись.

[Поддерживаемые алгоритмы Yubico](https://developers.yubico.com/PIV/Introduction/YubiKey_and_PIV.html).
