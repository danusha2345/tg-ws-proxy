# TG WS Proxy для Android

Android-клиент запускает то же Rust-ядро локально на телефоне и передаёт
Telegram ссылку на MTProto-прокси `127.0.0.1`. Отдельный сервер для базового
режима не нужен.

Версия **0.2.0** использует Rust-ядро **1.11.0** и новый интерфейс со светлой
и тёмной темами. Подключение и настройки разделены, ключ скрыт по умолчанию,
а состояния объясняют следующий шаг. Статус «Прокси запущен» подтверждает
готовность локального listener, но не доступность Telegram.

Сборка проверяется unit-тестами, lint и smoke-тестом на Android-эмуляторе.
Мобильная сеть, длительная фоновая работа и энергосбережение на реальных
телефонах требуют отдельных проверок.

## Установка

На [странице Releases](https://github.com/danusha2345/tg-ws-proxy/releases)
скачайте:

- `TgWsProxy_android_arm64-v8a.apk` — большинство современных телефонов;
- `TgWsProxy_android_universal.apk` — универсальная сборка для ARM и x86_64.

Разрешите установку из выбранного браузера или файлового менеджера. Стабильные
релизы начиная с `0.1.0` подписываются одним постоянным ключом. Предыдущие
alpha были подписаны временными CI-ключами, поэтому перед первым переходом на
`0.1.0` их потребуется удалить; при удалении сбросятся настройки и secret.

## Использование

1. Откройте приложение и разрешите уведомления.
2. Нажмите «Отключить ограничения» и подтвердите системный запрос исключения
   из оптимизации батареи.
3. Нажмите «Запустить прокси».
4. Дождитесь состояния «Работает».
5. Нажмите «Подключить Telegram».
6. Подтвердите добавление прокси в Telegram.

Пункт «Проверить обновления» получает только стабильные теги `android-v*`,
скачивает APK для телефона напрямую с GitHub, сверяет его с
`SHA256SUMS-android.txt` и передаёт системному установщику. При первом
обновлении Android попросит разрешить установку APK из TG WS Proxy.

Прокси работает через Android Foreground Service. Пока он запущен, Android
показывает постоянное уведомление с кнопкой остановки. Это ожидаемое поведение:
без foreground service система не гарантирует работу локального listener в
фоне.

Пока оптимизация батареи включена, приложение показывает предупреждение и
перед запуском предлагает открыть системный экран исключения. На Xiaomi,
Huawei, Honor и некоторых Samsung дополнительно может потребоваться разрешить
автозапуск и фоновую работу в настройках производителя.

## Возможности Android-версии

- Rust MTProto/WebSocket proxy на `127.0.0.1`;
- постоянное уведомление и запуск в фоне;
- системный запрос исключения из оптимизации батареи;
- direct WebSocket, Worker/CfProxy и TCP fallback;
- несколько пользовательских Cloudflare Worker-доменов и один прогретый
  Worker socket на DC;
- Fake TLS и masking upstream;
- генерация и защищённое хранение secret через Android Keystore;
- состояние, счётчики подключений и объём трафика;
- открытие Telegram и копирование `tg://proxy`;
- просмотр, очистка и отправка ротируемого лога;
- интерфейс на русском и английском;
- адаптивные элементы управления для узкого экрана и увеличенного шрифта;
- встроенная загрузка и SHA-256-проверка стабильных обновлений с GitHub.

Откройте «Настройки» для изменения порта, ключа и резервных маршрутов.
Поля имеют постоянные подписи. Пока прокси запущен, редактирование
заблокировано. Сохраните параметры перед следующим запуском. При смене
ключа нужно добавить прокси в Telegram заново.

Разрешение на уведомления запрашивается при запуске прокси. Предупреждение
о фоновой работе видно на главном экране, пока включена оптимизация батареи.

## Сборка

Нужны Android SDK 36, NDK `28.2.13676358`, JDK 17+ и Rust:

```bash
rustup target add \
  aarch64-linux-android \
  armv7-linux-androideabi \
  x86_64-linux-android
cargo install cargo-ndk --version 4.1.2 --locked

cd android
ANDROID_SDK_ROOT="$HOME/Android/Sdk" \
ANDROID_NDK_HOME="$HOME/Android/Sdk/ndk/28.2.13676358" \
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Gradle сам собирает JNI-библиотеки из `crates/android-bridge`.

## Что проверить

- подключение официального Telegram Android к `127.0.0.1`;
- сообщения, фото, видео и большие файлы;
- Wi-Fi и мобильную сеть;
- переключение между сетями;
- работу при выключенном экране;
- direct WebSocket, Worker/CfProxy, TCP fallback и Fake TLS;
- длительную работу и поведение энергосбережения.

В Issue укажите модель телефона, версию Android, маршрут и приложите лог без
secret.
